<Steps>

1. In wp-admin: **Plugins → Add New Plugin**, search for **agentprose** (the plugin's page: [wordpress.org/plugins/agentprose](https://wordpress.org/plugins/agentprose/)).
2. Click **Install Now**. The plugin bundles the matching agentprose release plus the pinned MCP-B polyfill.
3. **Activate.** The tools are live on every front-end page.
4. As an administrator, open any post and click 🔌 to see and run the tools.

</Steps>

Requirements: WordPress 6.3+, PHP 7.4+. No access to the directory from wp-admin? **Download** the zip on the [wordpress.org listing](https://wordpress.org/plugins/agentprose/) and upload it under **Plugins → Add New Plugin → Upload Plugin**.

Everything else (every setting, Cloud vs self-hosted, caching and CSP, uninstall, FAQ and the changelog) is in the [WordPress plugin section](../../wordpress/).

## Or: the script tag

Any WordPress site also works with the one-line snippet: agentprose sees `<link rel="https://api.w.org/">` and switches to the REST API on its own.

```html
<script src="https://cdn.jsdelivr.net/npm/agentprose@0/dist/agentprose.min.js" defer></script>
```
